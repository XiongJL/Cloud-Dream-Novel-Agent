## 修复范围

1. Python 从 Lexical 文档的文本节点判断是否有正文；保留原始序列化内容用于源版本、哈希检查。已确认的空章按 `new_chapter` 生成完整正文，目标仍是当前章，不会另建第502章。非空正文仍走原续写路径；没有可靠目标或必要上下文仍拒绝。
2. 篇幅解析识别“完成本章内容”，沿用既有优先级：用户明确字数、显式参数、小说整章设置、整章默认2300汉字。普通续写仍默认500汉字。明确要求300字等仍有效。
3. 仅有一次既有篇幅调整，未增加模型调用。调整结果离目标区间更远或没有改善时，保留调整前草稿；分别记录初始字数、调整字数、是否采用及两个阶段可观测的响应信息。该选择只核验篇幅，不声称判断了文学质量或情节覆盖。阶段用量也不能替代缺失调用的完整账单。
4. 流式活动记录每两秒最多一次、最多一个写入在途；首字节保留。结束任务时先停收活动、等唯一在途写入结束，再完成尝试，避免晚到片段回写。不会改变模型流读取、取消或其网络超时机制。
5. 状态事务先在事务外读取快照，事务内第一步以版本和状态 CAS 取得写锁，避免先持读锁再升级。提交草稿、状态版本和完成事件仍在同一事务内，失败整体回滚。事务限时15秒、获取事务等待5秒，给短写入留出锁等待余量；未添加无限等待、模型自动重试或放宽版本门禁。它仍不能保证在其他进程长期持锁时写入成功。
