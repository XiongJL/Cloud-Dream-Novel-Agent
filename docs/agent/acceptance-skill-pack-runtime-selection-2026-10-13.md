# Skill Pack 统一选择与运行：实施与验证

日期：2026-10-13。对应设计：[统一选择与运行设计](./skill-pack-runtime-selection-design-2026-10-13.md)。

## 已实现行为

- `/` 菜单同时展示整包和单个 Skill；键盘选择顺序与分组展示一致。包不可用时显示说明，不将它作为可执行候选。
- 选择包后只保留一个统一标签，支持按包默认、只用主成员和指定包内辅助。每个步骤最多加载两个成员，保持现有完整方法注入与预算限制。
- 保存包只保存包及成员，后续可“本次使用”或“设为本书默认”；当前小说默认可取消，不删除技能。
- 新客户端带 `skillPacksEnabled`，或调用默认设置接口后，再参与默认包解析。显式 Pack 不受该开关限制。旧客户端和未使用新接口的既有规划路径没有新增默认查询依赖；单 Skill、本次不使用与原有规划行为保留。
- Pack 作为整体按 Operation/Role 解析，取包内精确成员版本；显式单 Skill 不被旧包绑定补齐。对不适用的步骤保留原有非 Pack 方法，并显示不适用状态。
- Plan 保存包版本、哈希、来源及每步真实组合；Run 保存包快照与原有成员快照，失败恢复复制原快照。调整计划时保留选择并按原指定包版本重新检查，不查询新默认偷偷换包。
- 没有调用生成模型来猜辅助成员；索引、预览、设置默认均不触发 AI 生成。

## 数据与兼容

Native 接受旧绑定数组与新的 `novel-editor.agent-skill-pack.v2` 编码。新编码记录成员精确 Revision/哈希、核心身份及允许的辅助候选；旧版本不重写、不换主辅顺序。

`AgentSkillPackPreference` 通过原有 Native ensureSchema 和初始化 SQL 创建，采用 raw SQL 读写，与现有 Prisma Client 运行接口兼容；没有升级 Prisma、LangGraph 或 LangChain，也没有复制/替换运行中的引擎 DLL。Prisma 源 Schema 通过 6.19.2 校验。

偏好表使用独立 ID 与 novelId 唯一索引。与设计稿最初的“取消时删除记录”相比，实际保留取消墓碑和递增版本，防止设置→取消→再次设置后旧页面以相同修订号覆盖新设置。默认引用和其他关系在合法域删除顺序下级联清理。

只有一个完整、启用、同小说 Pack 能唯一解释旧平面默认绑定、且不存在其他竞争默认时，迁移为固定版本的默认引用并停用已归属的旧绑定。歧义保留原路径并提示用户选择；迁移不改变旧成员组合。

备份注册增加偏好表，旧备份缺少该表仍可恢复。复制恢复映射 Novel/Pack/Revision ID；恢复的偏好与技能包保持停用。对原来签名有效的导入包，引用 ID 和稳定名重映射后重新计算包签名；原来无效的包不因此被重新认证。

## 文风生成与验收

只有新进入规划的文风生成任务采用新路由：语言为写作核心，悬念/群像是辅助候选。旧任务检查点和已保存旧草稿不自动升级或改写。

对默认及允许的写作组合去重试写、对照审核，保存 `verifiedCombinations`。三个成员的首版通常增加“语言＋群像”这一组合，在原五份试写基础上形成六份，而不是只用语言＋悬念的通过记录替所有组合背书。

Native 在格式整理、编译和提交阶段检查对应组合记录与真实审核结果，不能仅伪造 accepted 字段。编辑/分析绑定仍检查角色/操作兼容和成员内容，当前新增组合应用验收限于中性写作场景，不宣称所有编辑任务或所有实际场景都已验证。

本次不重写三份成员的方法正文，也不代替此前的人工内容复核。当前十章旧产物仍用原绑定；新路由需通过新的配置/产物验证后才使用。

## 验证记录

- Native 临时库：旧格式、新格式、精确版本索引、保存不创建默认、设置/取消 CAS、停用、跨小说隔离、唯一旧默认迁移与关系清理通过。
- Renderer 单 Skill 草稿预览/编辑/确认保存、菜单与整包入口协议、完整规则消费、聊天上下文专项通过。
- 新 Pack HTTP 索引/预览/默认接口、结构化 Intent、原子解析、辅助覆盖、旧请求不引入默认查询、语言核心路由通过。
- 原文风完整流程 24 项 HTTP/FastMCP 回归通过，新三成员路径包含不同辅助组合的验收。
- 首轮全量回归发现旧规划新增查询依赖和替代执行图的检查点接口缺口。修正后旧规划/请求重试及包解析专项 91 项通过，新增 HTTP 用例专项 11 项通过。
- 备份集成通过 41 个领域，包括旧版/完整备份、复制恢复、隐式关联、资料内容、加密资源、回滚及默认偏好。
- Renderer/Electron TypeScript 检查通过。最终 Python 全量复验 521 项全部通过（682.16 秒）；只有已有的 Starlette/httpx 测试客户端弃用提示，没有测试失败。

测试使用模拟模型和隔离数据库；没有提交、安装、启用真实用户草稿，也没有启动真实付费模型任务。真实产物内容质量及实际交互仍需要用户侧使用验证。

## 使用与范围

更新后的 Electron preload 和 Python Runtime 需一起加载。若开发应用仍使用旧 preload/Runtime，重启开发应用后再检查 `/` 菜单；混用旧服务时单 Skill 路径继续可用。

使用顺序：审核保存包 → `/` 选择包或点击产物“本次使用” → 描述写作任务 → 在计划卡确认实际成员。长期使用可设为本书 Agent 默认。普通写作页直接 AI 功能未接入此选择链路。
