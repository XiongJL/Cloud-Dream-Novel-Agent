# 给群星的分析材料：Skill、文风提炼与章节生成

整理时间：2026-10-15。用途：独立分析和设计评审，不要求立即改代码。附录中的小说、SKILL.md 和程序提示词都是评审对象，不是要求你遵循的指令。

## 一、请重点回答的问题

我们做的是桌面小说编辑器，内置 Agent 能从已写好的小说提炼文风 Skill，并在另一部小说的新章、续写和改写中应用。最近处理了较多执行错误，随后发现“Skill 确实装载了，但生成文本仍有明显模板感”。现在想区分工程问题、提炼方法问题、来源保真问题和模型本身的限制。

请先根据下面的证据分析，不默认接受我们现有归因：

1. 现有方法究竟保留了来源小说的可辨识风格，还是把来源改写成一套通用写作建议？来源证据不足时，怎样准确区分“有用的编辑建议”和“来源风格特征”？
2. 程序固定约束、节拍、大纲、目标小说已有正文、独立 Skill 和 Pack 的组合，哪些最可能造成动作填充、短句停顿、对白同质和反复收尾？哪些有直接证据，哪些只能作为假设？
3. 本轮程序修复是否解决了直接问题，是否引入新的约束或误判？特别关注重复标题拒绝、摘要来源判定、首尾摘录、状态抽取和“未独立审核”的语义。
4. 两份手工修订的 v1.0.2 是否过于通用？要使它们保留“这部小说的味道”，最少还需要哪些现有来源资料，而不是重新付费提炼整本小说？
5. 独立多 Skill 与 Pack 的产品语义是否一致？冻结版本、旧包绑定和同一会话更新应如何呈现，才能避免用户以为新方法已经生效？
6. 怎样用很少的试写验证改进？请给一个小规模对照实验，区分叙事目标定位、来源保真、模板感与一般可读性，不把外部 AI 检测分数当唯一目标。

希望输出：按影响排序的结论、对应证据、仍缺的材料、最小修改建议、验证方法。请避免只增加更多禁词、更多通用自检或更长提示词。

## 二、产品约束与已确定的方向

- Skill 主要是方法说明。内置 Skill 可以有产品专用工具链；自定义 Skill 可用执行提示表达可拆分性，由程序判断任务、输入规模和依赖后编排，不能仅因 Skill 写了“分批”就授予工具或决定并发。
- 章节样本分析可以拆分并汇总，拆分只是原任务内部阶段；后续证据核验、内容审核和交付不能被绕过。
- 正文连续新写最多10章，按章顺序生成。后章依赖前章实际草稿和状态，不能将10章正文独立并行生成或一次请求吐完。
- 新 Skill 默认当前小说可见，可随时改为所有小说可见。“可见”不等于自动在每部小说启用，也不等于本书默认。
- 独立 Skill 支持显式多选，不限两个；完整方法必须抵达适用步骤的模型边界，预算不足明确失败，不偷偷删方法。
- Pack 仍按已发布的“主成员＋至多一个辅助成员”组合执行；目前不支持多个 Pack 堆叠，也不支持 Pack 与独立 Skill 混选。自动默认选择与显式多选的限制不是同一回事。
- 已开始任务锁定精确 SkillRevision。更新已发布 Skill 不自动修改旧任务或旧 Pack 的成员引用；同一会话下一次新任务可重新选择新版本。
- RAG 保持缺乏信息时按需获取，本轮没有强制所有章节生成都检索，也没有修改检索算法。
- 不为了修正文风重复分析原10章，不通过绕过证据审核让任务“成功”，不自动重新发送结果未知的收费请求。

## 三、最近问题与处理过程

### 1. 提炼链路的工程稳定性

出现过整本500章分析、系统错误未正常结束、取消卡住、数据库锁、网络错误缺少手动恢复、引文不逐字匹配导致整片失败、模型输出截断、草稿格式/审核失败和后续审核输入超限。

确认这些不是同一个根因：

| 问题 | 已确认原因/处理 |
| --- | --- |
| 失败后一直显示执行中、取消无响应 | 公共事件/状态持久化和后台任务收口存在断点；增加可见系统错误、权威状态核对、取消等待上限及未确认副作用说明。并非改一句 Skill 就能修复。 |
| `database is locked` / 磁盘满 | 有真实存储故障与并发压力记录；不能推断“超过300章必锁”。错误必须传播，已有分析要保留，不能自动重放所有任务。 |
| 分片引文错误 | 实例是“仔细思索”被改成“微微思索”，或截短对白后补引号。仍严格逐字核验，但局部剔除无效引文、降级对应结论；全片无有效证据仍失败。 |
| 网络错误没有重试入口 | 未确认收费请求被正确保留，但父任务缺少恢复描述；现提供手动核对/定向重请求，不把“没有收到结果”等同于“模型没有执行”。 |
| 十章分析后的审核“上下文窗口不足” | 一次实际为产品 `maxInputBytes=48000` 预检超65字节，尚未请求模型；不是已证实的模型窗口不足。现按审核成员投影相关例证，保留完整待审正文、规划、统计和边界，独立错误码区分。 |
| SKILL.md 反复格式失败 | 模型同时改正文与技术 Frontmatter，修订破坏结束分隔符等；内置文风成员改为模型写正文、程序维护技术头部，blocking 与 advisory 分开。 |
| 部分结果想直接收尾 | 用户可明确选择只使用已完成分析，冻结实际完成范围后继续专家/编写/审核，报告 N/T 和遗漏；不宣称全书已分析。 |

这些修改增强可恢复性，不证明真实生成质量已经提高。早期测试多数采用模拟模型；不能把多次不同时间的回归通过数累加成一次全量测试。

### 2. Skill 使用与版本困惑

- `/` 原来读取全部完整正文并逐个跨进程查询，多个 effect 重复刷新。改为元数据批量读取、并发去重、短缓存；执行时才加载完整方法和精确版本。
- 新增详情、范围设置及删除入口。删除为归档停用，保留历史修订；包与成员的引用、默认和正在运行任务受保护。
- 已选方法以标题标签显示，保留 `⋯` 和 `×`，版本移到详情/悬停；多选追加而不是覆盖。
- “v1.0.x”是某份用户 Skill 的内容版本；“内置提炼器1.3/1.4”是提炼方法版本；“Pack版本/绑定schema”又是另一个维度。改提炼器不会自动改旧产物。
- “旧版绑定”指历史 Pack 的组合/绑定格式，不表示完整方法没有装载，也不单凭这个标签判断执行失败。
- 用户确认本版本以后默认支持多 Skill 等能力后，删除了多余 capability gating 和旧签名猜测重调；保留旧数据、冻结版本、请求哈希和数据库升级所需兼容。

## 四、为什么“装载了 Skill”仍不等于写出来源味道

实际提炼不是直接把小说变成一段提示词，而是：

`获准来源 → 分片观察/引用 → 证据核验与汇总 → 成员规划 → 编写方法与示例 → 内容审核 → 中性试写对照 → 发布不可变修订`

中间每步都可能丢失具体表达机制，最后留下“增加细节、克制、短问短答、延迟揭示”等泛化技巧。规则应用明显，不代表风格保真。

早期提炼固定要求语言＋悬念，可能再加群像，导致没有充分来源证据也往这些维度套。新版内置提炼器1.4改为语言成员为核心，其余按证据和场景选择，允许单成员 Pack。增加有界来源画像、句段/引语统计、最多六章代表材料；至少五章时最多保留两章作为独立参考，候选编写不使用其证据。统计不是生成配额，粗统计也不等于已完成语义场景分类。

新版试写覆盖互动、过渡两个场景，对比无 Skill、单成员和实际 Pack，并加入来源保真与节奏变化检查。这些是已实现的程序契约，不是当前两份手工 v1.0.2 已经通过真实试写的证明。

用户曾提供腾讯检测截图显示100%“疑似AI”，且主观认为模板感明显。它是质量问题的反馈，不应解释成“100%概率由AI写作”，也不能据此定位某条提示词的责任。本材料没有测评该检测器。

## 五、最近一次真实生成审计：最重要的直接证据

审计对象是目标小说《功能验收-灯塔档案-20260916》中，用户输入“写新的一章”的任务。角色只有 writer，无 editor/reader 独立步骤。附录A为完整生成正文，附录B为该次实际编译的两份旧方法。

### 1. Skill 和上下文确实加载

- 实际使用两份 v1.0.1，完整编译方法共5136字符，已检查进入节拍及正文 provider 边界。不是“只把名字传给模型”。
- 锚点为已有第10章《潮退之后》，正文3381字符；前两章原文3301/3104字符；四章旧摘要，三章摘录，各约2399字符；另有小说/卷级同源拼接摘要、6名角色、14项物品、4张地图、6项设定、5条情节线。
- 正文模型为 deepseek-v4-flash，温度0.7，maxTokens=32768。实际正文调用输入27220 token，输出4698 token（含 reasoning816），该调用合计31918；不含节拍、状态抽取和报告等整轮费用。
- 装配记录没有省略 section，也没有正文输出截断。只保存了部分边界日志与持久化输入，没有逐字留存完整最终HTTP请求，不能把还原提示词当作原始抓包。
- 本次没有 `rag.ask` 或 `search.query`；业务库上下文装载不是 RAG。数据库存在120条 hash/local-hash-v1 索引，不表示本次用过，也不证明其召回质量。

### 2. 直接的程序缺陷

1. 新章节拍却复用“第10章 潮退之后”，继续执行已完成的调查、交接、整理、日志和信件收尾。已有末章已经完成这些功能，新稿又演了一轮。
2. 多份 `summaryFresh=true` 实际只是本地取正文开头220字符；哈希新鲜不等于情节摘要合格。末段状态缺失，卷/小说拼接重复。
3. `consistency.ok=true` 当时只依据资料存在/正文最小长度，根本没检查时间、人物知识、物品与语义重复。
4. 正文生成后状态抽取被3200输出上限截断；单章保存草稿并警告，但最终总结反而说“无告警”“没有读取正文”。这是警告和覆盖信息传递/报告失真。

### 3. 正文层面的编辑观察

- 多次手续复述、收拾归位、日志记录、照片/信纸和灯光结尾；很多段落没有形成新的选择或阻力。
- 人物对白整齐克制，彼此辨识度较弱；微动作承担过多情绪表达。
- 同章上午已经收到回执，傍晚又说“你的那份应该也快了”，没有说明是否另一份回执。
- “下巴浅痕是整夜没睡留下的”“手电扫过的水汽”等因果不实；“主灯一层一层”像为节奏拼接意象。
- 4500汉字目标与已收束的情节可能共同推动扩写填充；目标小说此前已有类似模板，作为前文参考也可能延续。这两点仍是推断，未经过对照实验。

## 七、两份当前 Skill：直接修订而非重新提炼

为节约用户费用，用受控 prepare/commit 流程直接更新现有两份方法，版本均为1.0.2。没有重新分析10章、没有调用模型、没有增加证据或提高来源置信度。附录C/D是完整发布文件。

- 语言风格：贴近人物的具体叙述与自然对白。
- 悬念与信息释放：证据驱动的疑问与局部解答。

语言成员强调人物此刻在意的事、具体用词、允许完整盘算/心理、因果驱动的句段与对白、删并同功能动作和收尾。悬念成员强调有可观察证据、局部解答改变行动、允许自然解释和过渡，不将每件事都变成谜题。示例重新采用中性内容，明确标注编辑示范、非来源原文。原证据尾部保留，Frontmatter 中原有适用情境/触发语义也仍存在，可能与更通用的新名称产生张力，请一并评估。

两份实际文件不是旧来源风格重新验收后的结果，而是基于已有边界的编辑修订。需要独立评审：是否改善了泛化禁令，却也稀释了来源的辨识度？是否仍有旧约束与新方法相互抵消？

旧 Pack 未自动升级到新成员，旧任务未改。相同会话中重新选择1.0.2并发起新任务可使用新内容；继续原失败任务按冻结版本恢复。

## 九、已验证什么、还缺什么

- 最近一轮：157项Python定向测试、15组桌面端专项、Renderer/Electron TypeScript检查通过；覆盖真实方法装配边界、编号、首尾摘录、预算、警告、恢复和批次写回。大多使用模型/数据库夹具。
- 两份1.0.2已通过实际发布接口保存并读回，但没有本轮修改后的真实模型对照试写，也没有新的外部检测结果。
- 附录A来自修复前的真实生成；不能用它判定修复后仍无效。
- 本材料未附来源小说完整原文/独立参考片段。因此能够分析模板和工程机制，不能最终断言与来源有多像。要评估保真，优先请求已保存来源画像、真实核验引文及不同场景的少量参考，不先重跑全量提炼。
- 新测试通过不等于未来不会网络断开、数据库竞争、模型幻觉或文学质量波动。

建议评审先形成优先级，不立即引入更多Agent层或自动重写循环。若建议实验，可固定同一模型/目标/事实，比较“无Skill、旧1.0.1、语言1.0.2、语言＋悬念1.0.2”在互动和过渡场景中的表现；只在任务目标已正确时比较风格，避免把重复章目标误当风格问题。

早上六点，他按时起来。生活间的窗外，海平面上一条灰白逐渐扩开，比前一天更亮了些。他洗漱完毕，上控制室巡检，主灯正常，备用设备正常，手动钥匙在位。他在值班日志上写下当日第一行，笔压很平。

下塔之前，他用抹布把控制室台面再擦了一遍。玻璃板下，父亲的照片和周鹤的信压得平整。窗外的光从东边进来，落在照片上，灰蓝色的海变成了一种更浅的蓝。

他转身下楼，铁门合上，脚步声在礁盘上响了几下，然后被海风盖住。

远处，老港区的塔吊开始动了，吊臂慢慢转了一个角度。灯塔的主灯在白天只留一盏低功率的巡查灯，但灯器本身是好的。沈砚走到礁盘脚跟，回头看了一眼塔顶。

然后他沿着海堤，往镇上的方向走去。

<agent_skill id="style.suspense.puzzle-delayed-reveal" revision="1.0.1" guidance="adaptive" position="primary">
[Purpose]
用于悬念与信息释放：解谜式疑点累积与延迟揭示相关的写作、修订或诊断；按目标场景与用户约束应用正文中的条件化方法，证据强度及降级边界见正文。

[Method]
## 适用与输出

用于已经有悬疑目标的场景中安排可观察线索、角色判断与信息释放。目标小说、大纲、人物知识和章节功能优先。写作时输出原创正文，诊断时输出问题与建议；普通过渡、人物相处或完成行动的章节可不启用额外悬念手法。

本次为既有方法的编辑修订，没有重新分析来源章节，也没有增加来源证据。保留可核验疑点和有依据的信息差，取消连续短疑问、每轮只解释一层、章末必须留谜的执行偏好。

## 信息释放方法

### 1. 从人物正在做的事建立问题

先明确人物此刻的目标、阻碍、已知事实与未知信息。有真实冲突时，让异常通过行动或观察自然出现。记录不同、数目不同、没有看到某物，并不自动构成“不可能同时成立”；先考虑记录范围、时间差、遗漏、记错和信息来源，再决定是否确有矛盾。

不要求每章有新规则、时间异常、身份反转或多个物证。一个有后果的问题可以支撑场景，不用堆叠相似疑点来维持紧张。

### 2. 区分看到的事实与得出的推测

人物可以根据线索猜测、怀疑和误判，但正文应让读者分清观察、他人说法和推论。两个物件相似不能直接证明同一制作者，重复声音不能独立证明同一剪辑者，物件失踪不能直接证明有人偷取。

若结论尚未充分成立，以人物当前认知表达，保留可检验的替代解释；不能靠叙述者宣布肯定来补足证据。允许角色因急迫作出选择，但行动选择不是证明猜测为真。

### 3. 按当前情境回答，不机械拖延

人物已经知道、能够说出且没有隐瞒动机的信息，可以一次说清。不能只因为要保留悬念，就用故意断句、噪声打断或反复“不能告诉你”延后每个答案。

若确有保密、自保、交换条件或知识不足，让人物的回答受该动机限制；解释、误导与停顿都应有情境原因。解释可以完成一个局部问题，再把行动带向仍未解决的问题。疑点累积不是禁止解答，悬疑对白也不必每一问只答半句。

### 4. 让证据对象和行动连续

呈现物证时明确在比对什么：纸片断口、袋上印记、声音片段或电路部件，各自只能支持相应的判断。不同材质的印记不等于纸片能够拼接，未观察到的内部结构不当成已看见的证据。

人物拿着、放下、收起、丢失物件的状态应连续。需要故意留空时，先建立最后一次可靠观察，再让人物承认不知道，避免把作者遗漏写成故事中的神秘事件。精确时间和次数仅在人物确实观察、计时或事件依赖它时使用。

这些是目标正文的连贯性检查，不是重新核验出的来源规律。

### 5. 结束方式服从本章功能

完成行动、作出选择、取得局部答案、关系改变、普通过渡和保留疑问都可以收束一章。已有章节目标决定采用哪一种；不额外添加灯闪、失踪物件、倒计时或神秘来者。

采用悬念结尾时，其问题应来自前文已发生的事实，并确实影响下一步行动。连续写多章时保留实际知识状态，允许兑现已有问题；不为每章制造同一种突然异常或同一轮问答。未来计划不能提前当成已发生事实。

## 修订与诊断

先检查现有目标、证据和推断，再处理重复疑问、无理由拖延和多余异常。能够自然解释的地方可以说明，已解决的问题不重新包装为谜团；必要时降低疑点密度，让人物行动和正常交谈推进场景。

自检：线索是否可观察；人物知道什么、如何知道；推断强度是否符合证据；物件状态是否衔接；隐瞒是否有动机；结尾是否完成本章功能。未采用反转、认知差、分批规则或未答结尾的场景，不以缺少这些手法判为失败。

## 原创中性示例：局部解释与剩余问题并存

快递员把包裹放在柜台上，说收件人已经签过字。赵岚认出签名是弟弟的，便问他什么时候来的。

“中午。说晚上过来拿，我才没送上楼。”

弟弟中午到过店里，这一点能解释。赵岚给他打电话，接通后先问包裹要放在哪儿。弟弟却说自己只替同事代签，没听说还要来拿。

赵岚没有把电话挂掉。她请快递员看看送货单，确认说“晚上来拿”的人是不是弟弟，还是他后来又接过另一个电话。

这个例子允许马上解释一部分，也允许先核对误会。它没有证明任何人撒谎；剩余问题通过人物下一步行动处理。它是编辑示例，不是来源证据，不迁移其中的道具和情节。

反例：“签名相同，所以一定是同一个人布的局。她问了三次，快递员都没回答。灯忽然灭了，包裹也不见了。”结论缺证据，沉默缺动机，新异常没有铺垫。定向修订为核对信息来源、明确人物诉求与包裹最后可见状态，不靠增加异常补悬念。

## 已有证据与降级

原方法来自单一密室解谜题材样本，观察支持可核验的矛盾、线索呈现与解释安排；具体误导类型、跨章兑现、群像诉求分化和出场节奏未完整核验。规则分批只有一句“惩罚性解释”可核，分段节拍未证；疑点累积属于单章支持；章末未答属于低置信可选项。

本次不提高这些置信度，不将它们写成必备项，不声称新增了支持章数或试写验收结果。源材料的具体谜题、专名、规则台词、人物关系、暴力与骂词不作为写作方法搬入目标小说。

当目标场景不需要悬疑、人物知识不足以支持推断，或继续加问题只会重复时，保留正常叙事，停止追加悬念。只有用户明确要求设计谜题而关键条件确实缺失时，才说明缺口；不因普通场景没有谜题就停止写作。

[Constraints]
- 遵循目标场景与用户约束；写作模式输出原创正文，诊断模式输出问题与建议。
- 不得复制来源作品的专名、长句、人物、设定或情节；未核验的方法不得伪称来源规律。
- 句长、对白占比、微动作、精确量值和悬念结尾均不作为通篇必备项；以人物行动和章节功能判断。
- 沿用原有证据边界；本次编辑修订未重新提炼来源、未增加证据或提高置信度。
</agent_skill>

<agent_skill id="style.language.compact-limited-pov" revision="1.0.1" guidance="adaptive" position="auxiliary">
[Purpose]
用于语言风格：紧凑限知叙述与对白驱动相关的写作、修订或诊断；按目标场景与用户约束应用正文中的条件化方法，证据强度及降级边界见正文。

[Method]
## 适用与输出

用于贴近人物有限认知的叙事、对白中的信息交锋，以及既有正文的语言修订。写作任务直接输出原创正文；诊断任务才输出问题与建议。已有章节、大纲和人物设定优先于本方法；未提供统计支持的节奏建议不作为验收条件。

本次是对已发布方法的编辑修订，没有重新分析来源章节，没有增加来源证据或提高置信度。保留有限视角、信息交锋和功能性描写；取消通篇短句、对白占比和微动作的默认要求。

## 写作方法

### 1. 保持有限认知，同时让人物真正思考

以当前场景的聚焦者组织感知、记忆、判断与选择。其他人的内心只在既定叙述视角允许时进入；限知场景中，通过他人的行为、话语和已知事实推测，并保留推测语气。

人物可以直接回忆、解释自己的顾虑、比较选项、承认害怕或作出判断。这些都是限知叙述的一部分。不要为了“展示”把每一种情绪换成握拳、指节收紧、喉结滚动、呼吸变化。需要心理过程时，把它写清楚，不限为一句极短判断。

### 2. 根据场景功能分配对白和叙述

有交涉、试探、利益冲突时，让对白承载人物的具体诉求、拒绝、隐瞒与信息差。台词同时回应说话者此刻想做的事，避免所有角色轮流解释设定或说神秘警告。

独处、调查、移动或回忆场景可以主要依靠叙述。空间关系、经历和判断若影响人物行动，可以连贯写成一段，不必改成对白。普通回应、闲话和生活细节有助于人物关系时允许保留，不要求每句话都升级冲突。

### 3. 句子跟随思路，段落跟随行动

同一个连贯观察或判断可以用完整的中长句表达；对话接话、突然反应或确实需要停顿处可以使用短句。长短句由内容决定，不设比例，不把句长本身当成问题。

独立短段应有实际的语义转折。不要机械拆成“他停住。回头。”“第一步。第二步。”，也不要在没有叙事作用时用“硬的。凉的。安静的。”代替完整感受。若目标章节本来采用这样的节奏，可以局部保留；自检只处理重复或空转，不强制改成另一种文体。

### 4. 细节服务人物与事件

保留能交代行动、职业经验、人物关系或后续判断的细节。普通叙述与关键线索可以并存，不要求每件东西都异常、每次停顿都暗示秘密。

半寸、几秒、几步等精确量值只有在人物确实测量、熟悉或需要据此行动时使用；不能测量的距离与时长按人物的实际感受表达。同一种握紧、摸索、侧头、看表或数拍动作反复出现而没有改变行动时，删去重复。

情绪可由动作、感觉、直接心理叙述或简洁命名表达，选择当前段落最有效的一种；不要求每一轮对白配一个动作。比喻只用于具体感受，避免同段反复把雾、光、声音拟成隐藏操作者，也不规定使用次数。

### 5. 保持目标小说自身的声音

以目标小说已写正文、人物经历与关系为依据安排口吻和叙述距离。来源样本的专名、谜题、场景装置和示例道具不迁入新故事。没有核验过的角色声音、感官顺序和段落分布，不编造为来源规律。

连续写多章时，接续前一章实际发生的事件、人物已知信息与结束状态；章节各自的功能不同，不能反复套用同样的等待、异常出现、物证比对、神秘警告和章末灯闪。允许调查推进、关系变化、行动完成和自然过渡成为一章的主要内容。

## 修订与自检

先保留事件功能与人物选择，再定向修订：视角越界、台词变成设定解说、重复微动作、无作用精确量值、重复短段和同一种比喻。正常心理叙述、必要背景和清楚的长句无需压缩。

自检只问：人物是否有可理解的诉求和判断；段落是否清楚；动作是否改变事件或刻画人物；读者是否被重复细节拖住。不得把“对白更多、句子更短、情绪不直说”设为通过条件。诊断与修订不得凭空改变关键事件；明确的情节修改要求由用户任务决定。

## 原创中性示例：允许自然叙述与正常回应

周宁没答应续租。店才开了半年，他还没把设备的钱挣回来，房东却要先收下一年的租金。他说月底给答复，回去算账才知道，就算一件东西也不买，剩下的钱也撑不到冬天。

“要不先关一个月？”妻子问。

“关了就没人来了。”

妻子把账本合上：“现在也没几个人来。”

这话不好听，但周宁知道她说得对。他原想再争两句，最后只问她晚上吃什么。账明天还得算，饭总不能不吃。

该例只说明有限认知、人物诉求与连续叙述可以并存，不规定台词数量、句长或动作密度。它不是来源证据，也不是要搬入目标小说的情节。

反例：“他握紧笔。两秒。她敲了三下桌子。冷的。谁也没有说话。”如果这些动作、量值和停顿既没有改变人物关系，也不参与判断，就只是人为制造紧张。修订时恢复人物要解决的具体事情，删去无功能细节，而不是补更多短句。

## 已有证据与迁移边界

以下保留原发布版的证据记录，不是本次新增统计：视角与叙述距离有 7 章支持、0 反例、0 未决；对白信息载荷有 5 章支持、0 反例、4 章未决；情绪外化与功能性描写有 2 章支持、0 反例、1 章未决；日常物象比喻有 2 章支持、2 章未决。

短促句长与单句成段只有 1 章支持；段落与焦点切换为 0 章支持、9 章未决；人物声音辨识为 0 章支持、3 章未决。比喻频率、感官描写次序、跨章兑现、钩子后效和人物弧光未核验。不能把这些项扩展成整部小说的必备文风，也不能因采用长句、直接心理或自然收束判为失败。

上述补充的节奏变化、动作去重与连贯性检查是针对目标任务的编辑建议，未经重新来源核验。题材不同或上下文不足时，按目标小说现有写法选择性应用；仅在确实缺少可写任务时说明最小缺口，不因未提供谜题或规则就停止正常写作。

## 方法定位

以人物眼前要处理的事组织叙述，让观察、判断、对白与行动形成连续的因果。应用时输出目标小说的新正文；修订时改正文；诊断时给出依据。下面的正向规格是依据已有核验范围所作的编辑细化，不声称重新分析了来源，也不是每段必须重复的模板。

## 正向写法

**叙述站在人物可知的位置。**先选他此刻在意的事，再决定写哪些细节。事实来自看见、听见、已知经历或明确转述；猜测保留人物自己的犹疑。可以直写他的盘算、偏见和误判，使读者知道一个动作为什么值得做，不用总靠捏紧手、停两秒代替心理。

**用词贴着具体处境。**物件、职业和关系由实际用途带出来；人物会怎样称呼它，就用怎样的词。一个细节若能改变他对人、事或下一步的判断，就值得展开；没有这个作用的走路、收拾、握紧、侧头可合写或略过。细节的感官形容应与所见相符，不因要显得克制而拼接不成立的因果。

**句段随思路展开。**需要比较、回忆、盘算时允许完整长句和连续叙述；突然发现或作出决定时可以短。段落围绕一个有变化的意思，不把每个微动作单独成段。同样一件事说清就继续，给有分量的反应留篇幅，不靠反复核对、反复归位维持节奏。

**对白是人物在做事。**一人想得到什么，另一人为什么答应、搪塞、纠正或拒绝，都来自当前关系。知道且愿意说的可以一次说明；没有动机的欲言又止不承担悬念。不同人物的措辞与反应以目标小说已经建立的身份、经历和关系为准，不擅自给所有人同一种冷淡腔调。来源人物声音辨识仍未核验，这一项是目标人物的编辑建议。

**叙述有取舍。**同一场戏中，信息或关系发生变化的地方展开，其余用自然过渡连接。跨场景沿用已经发生的事实，但不再把上一章的离场、交接和收束演一遍。需要结束时让这一场的事情或人物选择落定，不追加同功能的巡检、整理、看灯、回想来延长结尾。这些场景并非禁用；有新作用时仍可写。

## 原创中性示例（编辑示范，非来源原文）

小顾赶到车铺时，师傅还蹲在后轮旁。他以为只是补胎，过来就问能不能先骑走。

师傅把轮子转给他看。钢圈走到一半，擦着闸皮响了一声。

“胎补好了。这个不修，你骑两天还得回来。”

小顾算了算剩下的时间。公交已经赶不上，打车的钱够换半只轮子。他原本要催，话到了嘴边，改成问师傅能不能借他那辆旧车。

“五点前还。”

“我六点下班。”

师傅往店里看了一眼：“那就别停外头，我收摊时自己骑回去。”

这里用轮子的一次异常改变人物盘算，完整心理承担选择过程，对话解决眼前的事；不要求照搬修车题材、句长或对白比例。

反例：人物每次讲话都换一次握法、移一次目光；叙述者又解释这些动作“意味着他并不平静”。修订时把需要的判断写清，留下真正改变交流的动作，而不是把所有动作换成更隐晦的动作。

## 方法定位

让疑问来自人物要办的事和现有证据，让解答改变他的下一步。应用时输出新正文；修订时改正文；诊断时说明依据。这是已有方法的编辑细化，不新增来源证据或置信度。普通过渡和收束场景可以不启用悬念方法。

## 正向写法

**先有具体目的，再有疑问。**人物在找人、办事、确认一件会影响自己的事时，遇到与已知不符的信息。选择一个真正影响判断的缺口，给读者足以跟着想的材料。异常只说明眼前哪里不对，人物可以提出解释，但解释强度不超过证据。

**一轮交流或行动应带来变化。**一次询问可以得到完整的局部答案；一次核对可以排除误会，或让原先的解释不够用了。读者因此知道了新东西，人物也有了继续或停止的理由。进展不等于每次再冒出一个陌生人、时间点或暗号。

**信息差有实际来源。**人物知道什么、从哪里得知、为什么现在愿意说，都依目标小说确定。保密、顾虑和误解可以限制回答；知道且愿意说明时就直说。不同人物分别承担自己的利益和责任，不让所有对白轮流宣布“该说的都说了”。这项差异化是编辑建议，未被冒称为来源人物声纹规律。

**证据在场，读者能回看。**需要推断时把相关观察写在判断之前或附近。记录、转述、直接观察可以相互印证，但不自动证明同一幕后意图。新的解释应与物件最后状态、时间顺序和人物可知范围相接。已解决的问题进入已知，不在下一章重新装成谜题。

**解答落到行动和代价。**新答案改变人物的路线、决定、关系或对某件事的看法，就完成一次推进。收尾章可以让问题落定并留下具体余波；章末选择、离开、普通过渡都成立。主题性的句子可在最有效的位置出现，不必用重复场景和重复意象多次证明已经结束。

## 原创中性示例（编辑示范，非来源原文）

周宁到训练场时，场地已经锁了。教练电话里明明说六点，他看了眼手机，还差十分钟。

门卫说今天临时修灯，下午就清场了。周宁正要问教练为什么没通知，门卫又补了一句：“你们不是改到学校那边了吗？”

他翻开群聊。最上面那条是教练回复别人的“收到”，往上再翻，才看见换场地的通知。他昨天把群设成免打扰，一直没点进去。

事情说清了，他没再怀疑门卫。离开前他借了门卫的打气筒，把车胎打足；赶去学校还要二十分钟，迟到总比不去强。

这个示例让局部疑问被解释并带来行动，不暗示每次误会都要升级成阴谋。人物、场地、道具均为中性编辑示范，不是来源材料。

反例：同一问题问三遍仍无动机地不回答，接着增加一条匿名消息，让人物再次等待。应先确定每一轮得到什么或失去什么；没有变化的轮次删并，尚未得到证据的答案保留为假设。

## 已有证据与降级

原方法来自单一密室解谜题材样本，观察支持可核验的矛盾、线索呈现与解释安排；具体误导类型、跨章兑现、群像诉求分化和出场节奏未完整核验。规则分批只有一句“惩罚性解释”可核，分段节拍未证；疑点累积属于单章支持；章末未答属于低置信可选项。
