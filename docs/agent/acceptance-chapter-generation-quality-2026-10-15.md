# 新增章定位、记忆与文风方法修订验收

日期：2026-10-15。依据本轮生成审计的优先处理建议实施；RAG 的选择性调用策略保持原样。

## 已实现

1. **新增章定位。**节拍读取小说实际跨卷目录，区分锚点与新增位置，赋予新的全局章号；第10章后新增10章的标题编号为11–20。卷末插入使用卷末位置，改写保留原章号。将锚点末段与已完成的事实明确传给规划，不把大纲中的旧章目标继续当作新任务。与锚点同名的新增节拍在正文生成前拒绝；这个检查不能发现所有语义重复。
2. **记忆来源与章末。**摘要必须有语义生成来源且内容版本匹配，才作为语义摘要使用。历史 local/heuristic 记录仍保留，但续写上下文从获准回看范围的原文生成有界首尾摘录，每章最多1200字符，保留实际末段并标注中段省略。后续本地生成也不再将开头句子声明为“关键事实”。同源小说/卷摘要去重，局部拼接摘录标明非完整情节摘要，不虚构跨章状态。
3. **真实检查范围。**基础检查只记录最小正文长度和与锚点逐字重复的长段；人物知识、物品、时间、因果和来源文风仍标为未独立审核，不再用“存在世界观资料”判定一致性通过。审核界面展示实际检查项及生成警告。
4. **警告与交付贯通。**子章的警告、上下文来源、基础检查和状态增量保留到批次产物、模型交付清单及会话回执。正文副作用恢复快照也保留这些信息，避免恢复时丢失状态和警告。会话回执根据交付记录生成，完整报告提示词必须遵守实际覆盖和核验范围；写作交付记录未附审核结论时不冒充已审过。
5. **连续2–10章。**状态抽取采用独立任务预算，自动模式初始8192、最多一次上调至16384，仍受模型窗口和产品限制；手动模式尊重用户预算。新上下文通过 generationPolicyVersion=2 冻结本轮策略，所有多章批次须完成实际状态抽取后才能推进下一章。抽取失败保留正文检查点，恢复只重试核对。单章仍交付草稿并带警告。既有冻结检查点维持原输入策略和请求哈希，不为启用新策略重复收费生成历史正文。
6. **提炼编写方向。**完整 SKILL.md 与 contentOnly 两条文档编写路径都强调可辨识的正向写法、人物处境、信息取舍和对白目的；必要反例说明边界，不以通用禁令代替文风。编辑示例明确不是新来源证据。

## 使用与边界

Python变更须由新启动的Runtime加载。下一次新任务重新选择两份1.0.2成员即可，同一会话可继续使用。已创建任务按冻结修订恢复；旧Pack也不会自动换成员版本，不能用旧任务恢复来检验本轮新策略。

这次修复可观察的程序问题及方法方向，不保证下一篇作品的文风质量或某个检测器分数。建议先生成一个短场景，检查目标是否前进、人物声音与句段是否自然、警告与上下文覆盖是否如实显示，再决定是否扩展连续10章；无需再提炼10章。独立语义/文风审核仍需实际审核步骤或用户审阅，基础检查与状态证据抽取不能替代它们。
