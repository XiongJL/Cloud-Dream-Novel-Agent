# Skill 删除入口与引用处理验收

## 交互

- `/` 菜单中个人及小说 Skill、文风包的 `⋯` 增加“删除”。详情/范围弹窗也可进入同一删除确认框，内置 Skill 不提供删除。
- 确认框展示全局可见影响、将取消的小说默认与绑定数；可以取消、按 Escape 关闭。引用检查失败或删除失败时保留明确错误，必须重新加载影响后再确认。
- 成员仍被未删除的文风包当前版本或小说默认固定的旧版本引用时，禁止单独删除，并可直接进入关联包的确认框。
- 删除包只删除组合入口，保留独立成员。删除成功后更新列表、清空输入框中已删除对象的选择并重新读取本书默认。

## 存储与运行

- `agent_skill.delete.preview` 为只读影响预览；`agent_skill.delete` 在事务内重新核对目标、引用、默认、运行占用以及预览令牌，要求显式确认。
- 删除采用 `archivedAt` 加 `enabled=false`，历史成员和包修订不物理删除，草稿、聊天和历史运行不改动。
- 删除包将各小说引用标为 `source=cleared`，保留默认版本 CAS 与显式取消语义；删除单个 Skill 停用其绑定。包的其它成员及其它包不级联删除。
- 正在执行、取消、等待审批或等待用户输入的任务，以及排队/生成中的章节请求使用目标时，不允许删除。界面也阻止在当前工作执行期间进入删除。
- 新任务选择已删除对象会在可见性/可用性检查中失败，不静默继续执行。
- 无数据库迁移、无新依赖、无 Python 图执行变更。兼容已安装 Prisma 客户端：新增范围版本通过既有原生字段读取。

## 验证

- 新增 `test:agent-skill-delete`，使用临时 SQLite 和实际 AgentSkillStore：内置保护、确认检查、成员依赖、旧默认依赖、并发变更、运行占用、生成占用、两本小说默认清理、绑定停用、历史修订/发布草稿/正文章节草稿保留。
- 原有 Store、可见范围、目录缓存和方法消费测试通过，Renderer/Electron TypeScript 检查通过。
- Playwright 使用生产菜单与确认框、隔离内存桥：成员关联提示、删除包保留成员、删除失败后重新预览、取消/Escape 不删除、内置没有删除入口、成员删除后更新列表、360×640 确认框不越界。
- 当前开发应用实际 `agent_skill.delete.preview` 接口返回正常；没有调用真实删除接口，没有删除用户实际数据。
