# v0.5.1

本次更新迁移 MCP 接入方式，新增小说导出，并优化开发启动、编辑保存与界面体验。

## MCP 接入迁移

- 外部 MCP 网关迁移到 Python FastMCP，与内置 Agent 共享工具契约，继续保留原有 31 个外部工具及权限边界。
- 主要入口改为 Streamable HTTP，默认地址为 `http://127.0.0.1:18765/mcp`；使用独立 Bearer 令牌，仅监听本机回环地址，并保留 stdio 兼容入口。
- 在“设置 → AI → MCP CLI”中提供启用开关、运行状态、接入配置复制、协议测试和高级端口设置。
- 安装版内置 MCP 所需运行时，无需另外安装系统 Python 或 Node.js。关闭外部 MCP 不影响内置 Agent；断开客户端不会自动撤销已受理的后台章节任务。

## 小说导出与功能优化

- 首页和编辑页均可导出 TXT、DOCX，保留作品信息、卷章结构和正文；DOCX 包含目录。
- 支持整本导出、指定章节范围和按每 N 章自动分批，默认每份 500 章；各分片使用同一个已保存快照。
- 优化编辑保存队列、导出进度、失败重试和目标文件保护，避免导出尚未保存的旧内容或交付半套分片。
- 修复新开发检出加载过期 Prisma 客户端的问题，并在客户端、schema、SDK 和引擎一致时安全复用，减少 Windows 引擎 DLL 占用导致的启动失败。
- 调整部分界面布局与中英文文案。

## 发布回归修复

`v0.5.0` 的 Windows 发布测试因固定轮询窗口结束时后台检查点尚未写完而失败。本版本改为限时等待实际后台任务结束，保留原有失败恢复、重试和结果一致性断言；未修改生产业务逻辑。原 `v0.5.0` 标签保留，没有移动。

## 下载与升级

- Windows x64 安装版：`clouddream-novel-agent-setup-0.5.1.exe`
- Windows x64 便携版：`clouddream-novel-agent-portable-0.5.1.exe`
- macOS Intel：`clouddream-novel-agent-mac-x64-0.5.1.dmg`
- macOS Apple Silicon：`clouddream-novel-agent-mac-arm64-0.5.1.dmg`

升级前建议备份作品。升级后重启桌面应用及 MCP 客户端，并从设置页重新复制接入配置；HTTP 配置包含访问令牌，请勿公开分享。使用 MCP 时需保持桌面应用运行。

macOS 安装包仍未签名，首次启动可能需要在系统安全设置中允许。Word/WPS 中的目录更新、显示效果及完整桌面交互仍需实机确认，自动化结构测试不等同于这些人工验收。

本次不宣称新增更多写作工具、高层 Agent 委托或新版 MCP 协议的全面兼容。
