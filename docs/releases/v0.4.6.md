# v0.4.6

本次更新重点完善 Skill 的创建、选择、执行和结果审核，并修复 Agent 恢复、章节生成及备份恢复中的问题。

- 完善 Skill 目录、可见范围、发布审核和删除流程，支持多选 Skill 与作品级 Skill Pack 偏好。
- 改进文风提炼的来源路由、证据检查、质量校验和分段分析，增强中断后恢复能力。
- 更新内置“人物认知与行为”Skill，补充场景细节取舍、专业对白、重复解释与场景因果指导。
- 修复运行取消、网络失败传播、模型结果检查点锁及已完成结果展示，完善章节提示词、状态检查点与写后审校。
- 完善完整备份与恢复、备份保留策略和恢复进度展示，更新 DeepSeek Flash 名称及能力查询兼容。
- 修复空 Lexical 章节误判、整章篇幅选择、流式状态写入与事务竞争，完善章节序号解析和侧栏当前章定位。

## 下载

- Windows x64 安装版：`clouddream-novel-agent-setup-0.4.6.exe`
- Windows x64 便携版：`clouddream-novel-agent-portable-0.4.6.exe`
- macOS Intel：`clouddream-novel-agent-mac-x64-0.4.6.dmg`
- macOS Apple Silicon：`clouddream-novel-agent-mac-arm64-0.4.6.dmg`

各平台内置 Python Agent Runtime。macOS 包未签名，首次启动可能需要在系统安全设置中允许。

## 升级说明

本版本包含 Skill 可见范围与发布元数据的数据库升级，建议升级前备份作品。完整备份与恢复有所更新，详情见仓库中的 `BackupDesign.md`。自动化测试不替代实际作品阅读验收。

`v0.4.5` 的 Windows 构建因测试等待窗口过短失败，本版本修复测试同步方式；原标签保留，没有移动。
